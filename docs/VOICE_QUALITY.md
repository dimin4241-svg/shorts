# Выбор русского голоса

Проверка 26.10.2026. Пользователь прослушал macOS Milena и отклонил её как роботизированную. Технически исправное аудио и −16 LUFS не означают хорошую русскую речь. Поэтому Milena остаётся только бесплатным техническим демо, не рекомендуемым голосом канала.

В указанном пользователем предыдущем проекте использовался **Microsoft `ru-RU-DmitryNeural`** через `edge-tts`. Короткий частный аудиотест этого голоса получен на текущем сценарии. Голос присутствует в [официальном перечне Azure Speech](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts). Частное сравнение не является утверждением коммерческих прав на выгрузку Edge: мы не подтвердили их в опубликованных условиях. Интеграция Edge не добавляется как производственный обход Azure API.

Для штатного выпуска добавлен **официальный Azure Speech REST API** с тем же голосом. Требуются `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION` и явный бюджет. Текст экранируется как SSML; код не добавляет неподдерживаемые роли или эмоции. [Документация REST API](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech).

Перед склейкой renderer убирает только длинный технический хвост тишины в конце MP3. Начала записей и все паузы внутри фраз остаются нетронутыми; речь не ускоряется и не разрезается. Длина сцены рассчитывается по подготовленному звуку. Субтитры делятся на короткие фразы по длительности сцены; точное совпадение каждого слова требует проверенных таймингов. Автоматическое выравнивание речи не заявляется.

```bash
# Сначала хук; значение бюджета — пользовательский плановый предел, не счёт API
.venv/bin/python -m shorts_factory --voice-provider azure --voice ru-RU-DmitryNeural \
  --voice-preview 'Почему интернет между материками идёт по дну океана?' --max-cost-usd 0.10

# Затем все сцены для прослушивания
.venv/bin/python -m shorts_factory --pilot --voice-provider azure \
  --audio-only --max-cost-usd 1 --max-voice-cost-usd 1

# После проверки продолжить соответствующий каталог v1 теми же настройками
.venv/bin/python -m shorts_factory --pilot --voice-provider azure \
  --resume runs/ИМЯ-ЗАПУСКА/v1 --max-cost-usd 1
```

Запуск этих команд — явное разрешение на обращения в пределах оценочного резерва. Само наличие ключа не разрешает скрытые платные прогоны. Тариф и бесплатная квота зависят от аккаунта: проект не утверждает, что Azure бесплатен.

Дополнительно поддержан **местный нейросинтез Qwen3 VoiceDesign через MLX**. Это оригинально описанный голос, не копия «Дмитрия». Он требует отдельного прослушивания. [Оригинальная модель](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign) и [MLX-конверсия](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-4bit) заявляют Apache-2.0. [MLX Audio](https://github.com/Blaizzy/mlx-audio) — необязательная зависимость; основная установка её не загружает.

Первичная подготовка на Apple Silicon с совместимой macOS и Python 3.12:

```bash
python3.12 -m venv .venv-voice
.venv-voice/bin/python -m pip install 'mlx-audio==0.6.1' soundfile
.venv-voice/bin/python -c 'from huggingface_hub import snapshot_download; snapshot_download("mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-4bit", token=False)'
export SHORTS_LOCAL_TTS_PYTHON="$PWD/.venv-voice/bin/python"
.venv/bin/python -m shorts_factory --voice-provider local \
  --voice-preview 'Почему интернет между материками идёт по дну океана?' --max-cost-usd 0
```

Модель занимает примерно 2.3 ГБ; MLX 0.32.4 имеет колесо для macOS 26+. Если установленная система не поддерживается, основная студия продолжает работать с API-провайдерами. Веса хранятся в локальном кеше, не в Git. Сам синтез работает с `local_files_only=True` и отключённой сетью Hugging Face; он не устанавливает библиотеки, не скачивает веса и не подменяет голос автоматически. `--speech-speed` для этого движка должен быть `1.0`: монтаж не ускоряет запись. Описание `--voice` задаёт оригинальный тембр; клонирование реального человека не используется.

Голос выбирается по прослушиванию одного и того же текста. Проверить «оптоволокно», «длин волн», «несёт», «повреждён», естественные акценты, начало/конец фраз и паузы. Только после этого выполнять финальный рендер. Yandex `ermil` и ElevenLabs Multilingual v2 сохранены; без соответствующих ключей реального сравнения этих голосов не было.
