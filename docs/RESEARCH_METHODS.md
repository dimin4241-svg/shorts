# Исследование и измерение: методы и границы

Проверено 26 октября 2026 года. Время каждого запуска берётся из системных часов
и сохраняется с часовым поясом в `researched_at` / `observed_at`, а не зашито в код.
Рейтинг — редакционная гипотеза, а не вероятность вирусности или прогноз просмотров.

## Доступность источников

| Источник | Реализованный доступ | Ограничения |
|---|---|---|
| YouTube Data API v3 | `YOUTUBE_API_KEY`, официальный `search.list` и `videos.list`; окна 72 часа, 7 и 30 дней | Без ключа — `unavailable`, без сетевого запроса; API расходует квоту, число HTTP-запросов ограничено |
| Google Trends | Явно включаемый публичный RSS `https://trends.google.com/trending/rss?geo=RU`; ручной CSV из Trending now или Explore | RSS — текущий снимок, не история за три окна; география не определяет язык и возраст |
| TikTok Creative Center | CSV пользователя: доступный официальный экспорт или ручное перенесение видимых строк | Автоматического сбора и закрытого API нет; доступ к интерфейсу и странам может отличаться |
| YouTube Studio | Локальный CSV на английском или русском, UTF-8/BOM, запятая, `;` или табуляция | Нужна таблица по роликам; отсутствующие показатели остаются `null` |
| YouTube Analytics API | Явное `opt_in=True`, существующий OAuth access token пользователя | Один отчёт до 200 роликов; нет автоматического входа, получения токена или публикации |

Живая проверка Google Trends RU RSS: `2026-10-26T05:00:36Z`, HTTP 200,
10 записей. Это проверка работоспособности источника, не доказательство тренда
для темы кабелей. YouTube с реальным ключом и приватная аналитика в этом запуске
не проверялись; тесты ответов этих API выполняются на моках.

[Google описывает RSS и CSV в Trending now](https://support.google.com/trends/answer/3076011?hl=en)
и [экспорт CSV из Explore](https://support.google.com/trends/answer/4365538?hl=en).
Регион RU используется как доступный географический сигнал; русскоязычная
аудитория шире одной страны. При отказе, CAPTCHA или пустом ответе результат
помечается недоступным, без подстановки другой страны.

[TikTok описывает Creative Center](https://ads.tiktok.com/resources/help/article/creative-center)
и [доступные фильтры Trends](https://ads.tiktok.com/resources/help/article/how-to-use-trends).
Общедоступный интерфейс не означает наличие универсального официального CSV
экспорта. Для импорта можно подготовить таблицу `hashtag,views,period,region,url,exported_at`.
Значения сохраняются как экспортированы; рекламная подборка не объявляется
репрезентативной органической аудиторией. Не обходятся авторизация и ограничения.

## YouTube: выборка, а не перепись

Для каждого запроса вызывается `search.list` с `type=video`, `relevanceLanguage=ru`,
`publishedAfter`, `publishedBefore`, `order=viewCount`, `videoDuration=short`.
Затем `videos.list` получает длительность и открытые счётчики. По умолчанию —
одна страница до 10 результатов на окно, без автоматической пагинации и повторов.
`max_results` допускает 1–50, `max_requests` по умолчанию 90. Регион можно передать
отдельно: это доступность видео в стране, а не страна зрителя. Индекс поиска
может запаздывать; сортировка и фильтры могут давать неполную выборку.

Согласно [официальному описанию поиска](https://developers.google.com/youtube/v3/docs/search/list),
`short` означает длительность менее четырёх минут. Это **не** надёжный признак
YouTube Shorts; соотношение сторон и факт распределения в Shorts не устанавливаются.
Поэтому у каждого результата `shorts_classification=unverified`; фильтр до трёх
минут — лишь дополнительный кандидатный признак. Предпочтение русского языка
также не исключает другие языки и не проверяет возраст 16–44.

Из [ресурса videos](https://developers.google.com/youtube/v3/docs/videos)
сохраняются дата публикации, длительность, просмотры, лайки и комментарии при
наличии. `viewCount` — накопленный счётчик, не engaged views. `views / age_hours`
помечается как приблизительный темп за всё время, не измеренный рост; до возраста
один час он не вычисляется. Пересекающиеся окна нельзя складывать. `totalResults`
— приблизительный результат поиска, не число конкурирующих Shorts. Скрытые,
удалённые, прямые эфиры и не соответствующие окну записи отбрасываются.

Для двух сохранённых отчётов `compare_youtube_snapshots(previous, current)`
вычисляет реальное изменение счётчика между наблюдениями **одного video ID**.
Отрицательное изменение сохраняется как коррекция счётчика без вычисления темпа
роста. Изменившиеся выборки поиска и разные языки зрителей остаются ограничением.

Секреты не включаются в отчёты и сообщения ошибок. Ошибки квоты, тайм-ауты,
неверные ответы и предел запросов явно дают `unavailable`. Автоматических
повторов нет: решение о новом запуске остаётся контролируемым.

## Прозрачный рейтинг идеи

`score_idea` требует все шесть редакционных оценок и проверяет их диапазоны:

| Компонент | Максимум |
|---|---:|
| `audience_interest` — понятный массовой аудитории вопрос | 25 |
| `originality` — самостоятельный угол и хук | 20 |
| `visual_story` — наглядная причинная история | 20 |
| `retention` — последовательное раскрытие вопроса | 15 |
| `timeliness` — актуальность или устойчивая полезность | 10 |
| `verifiability_accessibility` — факты, права и доступность производства | 10 |

Сумма от 0 до 100 сохраняется вместе с разбивкой и пределами. Отсутствующая
метрика популярности не становится нулевой и не превращается в подтверждение
интереса. В контент-плане редакционные оценки и реальные наблюдения различаются.

## Импорт Studio

В YouTube Studio: Analytics → Advanced mode / «Расширенный режим» → таблица по
видео → Export current view / экспорт → CSV.
[Официальные инструкции по экспорту](https://support.google.com/youtube/answer/9717005?hl=en).
Выберите нужные показатели; одного универсального отчёта со всеми метриками нет.

```python
from datetime import datetime, timezone
from shorts_factory.performance_lab import import_studio_csv, analyze_performance

rows = import_studio_csv("Table data.csv", observed_at=datetime.now(timezone.utc))
report = analyze_performance(rows)
```

Сохраняются отдельные значения `views`, `engaged_views`, `shorts_feed_impressions`,
`viewed_percent`, `swiped_away_percent`, средняя длительность/процент просмотра,
доступные повторные просмотры, подписки и источник трафика. Обычные `Impressions`
не сопоставляются с показами в ленте Shorts. `Subscribers` трактуется как чистое
изменение, а не как новые подписчики. Доступны отдельные расчёты новых и чистых
подписок на тысячу обычных просмотров с явно обозначенным знаменателем.

Пустые ячейки, тире и некорректные числа становятся `null`, а не нулём.
Дата публикации без времени сохраняется как день; время и часовой пояс не
выдумываются. Импорт сохраняет имя CSV, номер строки и время наблюдения.
Можно добавить `Report start` / `Report end` («Начало периода» / «Конец периода»)
в формате ISO, если исходный CSV не содержит период отчёта. `observed_at`
означает время исходного снимка: при импорте старого файла передавайте реальное
время экспорта. Без явно переданного `observed_at` поле содержит только время
импорта с пометкой `observation_time_basis=import_time_export_date_unknown`:
возраст не вычисляется, сравнения и рекомендации по таким записям отключены.
Явный снимок CSV отмечается `explicit_export_observation`, живая выгрузка API —
`api_fetch_time`.

Если доступны точки удержания, дополнительная колонка `retention` принимает JSON:
`[{"second":1,"percentage":92},{"second":2,"percentage":86}]`.
Это явный перенос реальных данных пользователя, а не автоматическое выравнивание.
Значения процента просмотра выше 100% допустимы, но не объявляются числом повторов;
`views - engaged_views` также не используется как число повторных просмотров.

Официальные определения [метрик Analytics](https://developers.google.com/youtube/analytics/metrics)
и [показателей Shorts](https://support.google.com/youtube/answer/12942217?hl=en)
могут изменяться; отчёты разных периодов и определений требуют осторожности.

## Официальный Analytics API

```python
import os
from shorts_factory.performance_lab import import_analytics_api

rows = import_analytics_api(
    bearer_token=os.environ["YOUTUBE_ANALYTICS_ACCESS_TOKEN"],
    start_date="2026-10-01", end_date="2026-10-26", opt_in=True,
)
```

Токен пользователя должен иметь scope
`https://www.googleapis.com/auth/yt-analytics.readonly`. Он никогда не сохраняется
в отчёте. Код делает один `GET https://youtubeanalytics.googleapis.com/v2/reports`
с `ids=channel==MINE`, `dimensions=video`, отдельными `views` / `engagedViews`,
средней длительностью/процентом и новыми/потерянными подписчиками.
[Официальный reports.query](https://developers.google.com/youtube/analytics/reference/reports/query)
и [совместимые отчёты](https://developers.google.com/youtube/analytics/channel_reports).

У этого запроса нет длительности и даты публикации, точек удержания, показов
в ленте и viewed/swiped: они остаются `null`. Для сравнения по возрасту и длине
нужны дополнительные метаданные. Отдельный отчёт удержания в API использует
`elapsedVideoTimeRatio`; не обещается автоматическая посекундная точность.

## Сопоставимость и неопределённость

Сравнение использует возраст **на момент снимка**, длительность ±20%, отношение
возрастов не более 1,5, одинаковые источник трафика и период отчёта. Повторные
выгрузки одного video ID не считаются независимыми роликами. Если период отчёта
неизвестен, сравнение предварительное, рекомендации не формируются. Дата без
времени даёт возраст с неопределённостью до суток, на молодых роликах особенно.

Менее 1000 engaged views (или, при их отсутствии, обычных views с отдельной
пометкой) отмечается как малая выборка. Это редакционный порог, не гарантия
статистической значимости. Для советов нужны минимум четыре сопоставимых ролика
с достаточной выборкой и известный период, а результаты всё равно остаются
наблюдательными гипотезами. При проценте просмотра ниже медианы сопоставимых
роликов предлагается проверить более короткий сценарий и смысловую смену схем
или действий объектов в середине истории, сохранив естественный темп речи.
Если процента нет, допускается явно обозначенный показатель AVD/длительность;
он сравнивается только с таким же показателем, без смешивания методик.
Среднее значение не объявляется доказательством места потери зрителей.
Интервал Wilson вычисляется только из явных `Viewed count` / `Swiped away count`;
просмотры и показы не подставляются в качестве знаменателя. Повторяющиеся
зрители нарушают предположение о независимых испытаниях.

Нет автоматического выбора «победителя», обещаний охвата, накруток или публикации.
