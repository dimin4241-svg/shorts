# Shorts Factory — AI Shorts / Reels / TikTok

Original small Python project that turns **one topic into a vertical 9:16 MP4**: concise Russian storyboard, AI scene artwork, voice, legible baked-in captions, editable `.srt` and saved source assets. Built so that **Codex or Claude Code can operate and extend it** on your Mac. This is a standalone clean-room implementation inspired by the workflow idea of [Animator](https://github.com/ashishjamarkattel/Animator); it **does not include or relicense Animator code**.

> No tool can guarantee a video will go viral. Test real viewer retention and revise hooks. The app **does not automatically post** anywhere or fabricate analytics.

## Two ways to make visuals

| Option | Result | API key |
|---|---|---|
| `--image-provider openai` | True AI-generated raster illustration / photo-like visuals using GPT Image | `OPENAI_API_KEY` |
| `--image-provider claude-svg` | Claude writes SVG vector drawing code, validated & rendered into PNG | `ANTHROPIC_API_KEY` |

**Important:** Codex is the coding agent that builds/runs this pipeline; it is **not** itself a headless image-rendering API. Claude's Messages API writes SVG drawing code, **not photo-realistic raster images**. For images choose the OpenAI Images API. Storyboards may be generated by either Claude or OpenAI. Voice supports **native Russian Yandex SpeechKit**, **ElevenLabs Multilingual v2**, OpenAI TTS (legacy), macOS Russian `say`, or a no-voice demo.

## Русская озвучка — рекомендуемые настройки

Use these engines for Russian Shorts:

- **Yandex SpeechKit** (default): choose \`ermil\` (male), \`zahar\` (male), \`jane\` (female), or \`marina\` (female). Setup: add \`YANDEX_API_KEY\` from a Yandex Cloud service account to your local \`.env\`. The project uses the official v1 TTS form API. For Russian homographs, supports a user-editable stress dictionary.
- **ElevenLabs**: choose a real Russian-speaking voice in ElevenLabs, put \`ELEVENLABS_API_KEY\` and \`ELEVENLABS_VOICE_ID\` in \`.env\`. The system uses \`eleven_multilingual_v2\` and includes preceding/following scene text for continuity.
- **OpenAI**: extra comparison option. Uses a Russian speech-style instruction and voice \`cedar\` by default, although OpenAI says the voices are primarily optimized for English. **OpenAI has announced that the legacy Speech API models (\`gpt-4o-mini-tts\`, \`tts-1\` and \`tts-1-hd\`) shut down January 6, 2027**; plan a later migration.
- **macOS \`say\`**: free but less natural; auto-select an installed Russian voice. There must be a Russian voice installed in macOS system settings.

**Quick standalone voice audition**, no script generation or images:

\`\`\`bash
# Recommended budget-friendly first candidate: native Russian voice
python -m shorts_factory --voice-provider yandex --voice ermil \
  --voice-delivery energetic --speech-speed 1.04 \
  --voice-preview 'Ты когда-нибудь задумывался, что будет, если интернет исчезнет на целые сутки?'

# Premium candidate: set ELEVENLABS_VOICE_ID in .env
python -m shorts_factory --voice-provider elevenlabs \
  --voice-delivery storytelling --speech-speed 1.02 \
  --voice-preview 'А теперь представь: во всём мире внезапно пропал интернет.'

# For a different Russian female/male Yandex voice
python -m shorts_factory --voice-provider yandex --voice jane \
  --voice-preview 'Почему молния появляется раньше, чем мы слышим гром?'
\`\`\`

Created file is in \`runs/voice-preview-*/audio_00.mp3\`. Real API calls cost money; \`--demo\` and \`--plan-only\` do not call paid services.

**Correct accents, ё and abbreviations** by keeping a reviewed JSON file:

\`\`\`bash
cp glossary.example.json glossary.json
python -m shorts_factory --topic 'Как работает искусственный интеллект?' \
  --script-provider anthropic --image-provider openai --voice-provider yandex \
  --voice ermil --speech-speed 1.04 --voice-delivery energetic \
  --glossary glossary.json --seconds 30
\`\`\`

\`glossary.json\` can contain \`replacements\` (e.g. \`"ИИ": "искусственный интеллект"\`) and \`yandex_stress\` (e.g. \`"замок": "зам+ок"\`, plus sign before stressed vowel). Stress substitution is case-sensitive and whole-word-only to avoid corrupting unrelated words. **Review homographs before rendering**: a global rule for \`замок\` could be incorrect in another sentence. To protect privacy, do not submit secret scripts to external providers.

**Mastering:** audio is encoded at AAC 48 kHz / 160 kbps; FFmpeg loudness normalization targets -16 LUFS and limits peaks to -1.5 dBTP, with a short end fade to reduce clicks. Captions remain scene-timed. The code currently sends TTS per scene, not as a single continuous recording: for short videos it is reasonably practical, but speech may not be perfectly seamless. ElevenLabs context helps.

**Note:** The best voice depends on the exact voice ID, wording and listening test. These providers are candidates, not a scientifically proven voice-quality ranking. Music is intentionally off by default so it does not mask Russian narration.


## Install on macOS

```bash
git clone https://github.com/dimin4241-svg/shorts.git
cd shorts
brew install ffmpeg
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
cp .env.example .env
```

Edit `.env` locally and add **only** the keys you need. Set `OPENAI_API_KEY` for AI images, `ANTHROPIC_API_KEY` for Claude scripts/SVGs, and `YANDEX_API_KEY` (or ElevenLabs credentials) for natural Russian speech. API usage may incur charges independent of your ChatGPT/Claude subscriptions. Set cost/billing caps at each provider. Never send keys in chat or commit them.

### Check everything for free

```bash
python -m shorts_factory --topic 'Почему самолёт летает?' --demo --width 360 --height 640 --fps 12 --seconds 12
```

This local demo generates **placeholder cards and a demo script**, not AI artwork. No API keys or paid requests. The MP4 is inside `runs/<date>-<topic>/v1/short.mp4`.

### Real video — OpenAI imagery + Claude script

```bash
python -m shorts_factory \
  --topic 'Что будет если Земля остановится на одну секунду?' \
  --script-provider anthropic \
  --image-provider openai \
  --voice-provider openai \
  --style cinematic \
  --seconds 30
```

### Mostly Claude: scripts + vector drawings, free macOS narration

```bash
python -m shorts_factory \
  --topic 'Почему космос тёмный?' \
  --script-provider anthropic \
  --image-provider claude-svg \
  --voice-provider macos \
  --style whiteboard \
  --seconds 30
```

For Russian macOS voices, see `say -v '?'`. Add `--voice <name>` if installed; default uses your system voice. This mode still makes paid Anthropic API calls for script+SVG, but no paid voice calls.

### OpenAI-only mode

```bash
python -m shorts_factory --topic 'Почему мы видим молнию раньше грома?' \
  --script-provider openai --image-provider openai --voice-provider openai \
  --style infographic --seconds 30 --variants 2
```

`--variants 2` makes distinct hooks/scripts, **and bills separately** for all generated assets. Max 3 variants per call. By default only one is generated. To inspect before paying:

```bash
python -m shorts_factory --topic 'Почему самолёт летает?' --plan-only
```

## Output per variant

```text
runs/2026...-short/
  v1/
    storyboard.json       # review and edit narration before public posting
    image_00.png ...      # saved original generated artwork
    image_00.svg ...      # only in claude-svg mode
    audio_00.mp3 ...      # generated voice, if chosen
    frame_00.png ...      # composition with burnt-in Russian captions
    subtitles.srt         # timed at scene boundaries; optional platform captions
    metadata.json         # title, description, provenance, runtime
    short.mp4             # H.264/AAC 1080x1920, 24 fps (default)
```

### Current boundaries

- Captions are visible but **not word-by-word karaoke**; `.srt` is timed per scene.
- Portrait videos are still illustrations with gentle fades, **not full stroke-by-stroke Animator-style whiteboard animation**. Upgrading to that is a distinct rendering task.
- Claude SVG generation sometimes returns invalid output; safety validation rejects unsupported SVG, rather than falling back to dangerous SVG features.
- No real-time viral trend research, data-driven hook scoring or YouTube/TikTok publishing. Those need explicit platform connections and verified performance data.
- The `gpt-image-1-mini`, OpenAI voice and Claude model defaults can be changed via `.env` if your API access differs. Check your provider's current model list.
- Commercial use and media rights depend on the chosen API provider terms; review them separately.
