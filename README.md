# Shorts Factory — AI Shorts / Reels / TikTok

Original small Python project that turns **one topic into a vertical 9:16 MP4**: concise Russian storyboard, AI scene artwork, voice, legible baked-in captions, editable `.srt` and saved source assets. Built so that **Codex or Claude Code can operate and extend it** on your Mac. This is a standalone clean-room implementation inspired by the workflow idea of [Animator](https://github.com/ashishjamarkattel/Animator); it **does not include or relicense Animator code**.

> No tool can guarantee a video will go viral. Test real viewer retention and revise hooks. The app **does not automatically post** anywhere or fabricate analytics.

## Two ways to make visuals

| Option | Result | API key |
|---|---|---|
| `--image-provider openai` | True AI-generated raster illustration / photo-like visuals using GPT Image | `OPENAI_API_KEY` |
| `--image-provider claude-svg` | Claude writes SVG vector drawing code, validated & rendered into PNG | `ANTHROPIC_API_KEY` |

**Important:** Codex is the coding agent that builds/runs this pipeline; it is **not** itself a headless image-rendering API. Claude's Messages API writes SVG drawing code, **not photo-realistic raster images**. For images choose the OpenAI Images API. Storyboards may be generated by either Claude or OpenAI. Voice supports OpenAI TTS, macOS `say`, or silent demo.

## Install on macOS

```bash
git clone https://github.com/dimin4241-svg/shorts.git
cd shorts
brew install ffmpeg
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
cp .env.example .env
```

Edit `.env` locally and add **only** the keys you need. Set `OPENAI_API_KEY` for AI image+voice; `ANTHROPIC_API_KEY` if you want Claude scripts and SVG vectors. API usage may incur charges independent of your ChatGPT/Claude subscriptions. Set cost/billing caps at each provider. Never send keys in chat or commit them.

### Check everything for free

```bash
python -m shorts_factory --topic 'Почему самолёт летает?' --demo --width 360 --height 640 --fps 12 --seconds 12
```

This local demo generates **placeholder cards and a demo script**, not AI artwork. No API keys or paid requests. The MP4 is inside `runs/<date>-<topic>/v1/short.mp4`.

### Real video — OpenAI imagery + Claude script

```bash
python -m shorts_factory \
  --topic 'Что будет если Земля остановится на одну секунду?' \
  --script-provider anthropic \
  --image-provider openai \
  --voice-provider openai \
  --style cinematic \
  --seconds 30
```

### Mostly Claude: scripts + vector drawings, free macOS narration

```bash
python -m shorts_factory \
  --topic 'Почему космос тёмный?' \
  --script-provider anthropic \
  --image-provider claude-svg \
  --voice-provider macos \
  --style whiteboard \
  --seconds 30
```

For Russian macOS voices, see `say -v '?'`. Add `--voice <name>` if installed; default uses your system voice. This mode still makes paid Anthropic API calls for script+SVG, but no paid voice calls.

### OpenAI-only mode

```bash
python -m shorts_factory --topic 'Почему мы видим молнию раньше грома?' \
  --script-provider openai --image-provider openai --voice-provider openai \
  --style infographic --seconds 30 --variants 2
```

`--variants 2` makes distinct hooks/scripts, **and bills separately** for all generated assets. Max 3 variants per call. By default only one is generated. To inspect before paying:

```bash
python -m shorts_factory --topic 'Почему самолёт летает?' --plan-only
```

## Output per variant

```text
runs/2026...-short/
  v1/
    storyboard.json       # review and edit narration before public posting
    image_00.png ...      # saved original generated artwork
    image_00.svg ...      # only in claude-svg mode
    audio_00.mp3 ...      # generated voice, if chosen
    frame_00.png ...      # composition with burnt-in Russian captions
    subtitles.srt         # timed at scene boundaries; optional platform captions
    metadata.json         # title, description, provenance, runtime
    short.mp4             # H.264/AAC 1080x1920, 24 fps (default)
```

### Current boundaries

- Captions are visible but **not word-by-word karaoke**; `.srt` is timed per scene.
- Portrait videos are still illustrations with gentle fades, **not full stroke-by-stroke Animator-style whiteboard animation**. Upgrading to that is a distinct rendering task.
- Claude SVG generation sometimes returns invalid output; safety validation rejects unsupported SVG, rather than falling back to dangerous SVG features.
- No real-time viral trend research, data-driven hook scoring or YouTube/TikTok publishing. Those need explicit platform connections and verified performance data.
- The `gpt-image-1-mini`, OpenAI voice and Claude model defaults can be changed via `.env` if your API access differs. Check your provider's current model list.
- Commercial use and media rights depend on the chosen API provider terms; review them separately.
